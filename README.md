📝 Task Manager Application

A full-stack Task Management System with role-based authentication, interactive dashboards, analytics charts, and report generation. Designed to help users and admins efficiently manage, monitor, and analyze tasks.

🚀 Key Features
👤 Authentication & Authorization

Secure User & Admin login

JWT-based authentication

Role-based access control (RBAC) - ADMIN token - 123456

📋 Task Management

Create, update, delete tasks

Mark tasks as completed / pending

Task descriptions & timestamps

User-specific task visibility

📊 Dashboard & Analytics

Interactive dashboard with charts & bars

Task statistics (completed vs pending)

User activity overview

Admin-level analytics

📑 Reports

Generate task reports

Download reports (PDF / CSV, if implemented)

Date-wise and status-wise filtering

🛠 Admin Panel

Admin dashboard with global statistics

View and manage all users’ tasks

Monitor overall system activity

💻 UI & UX

Responsive design

Clean and intuitive interface

Optimized for desktop and mobile
